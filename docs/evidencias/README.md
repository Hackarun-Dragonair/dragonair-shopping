# Evidências

Critério "Cumprimento das missões e qualidade das evidências" vale 20%. Registrar enquanto acontece, não no fim.

**Nome dos arquivos:** `m<missão>_<dia>-<hora>_<descricao>.png`
Ex.: `m1_12-2130_quadro-ideias.png`, `m2_13-2040_teste-cadastro-falhou.png`, `m2_13-2055_teste-cadastro-corrigido.png`

**O que registrar:** fotos do quadro/ideação, prints de testes (falha → correção), telas do app em cada versão, comprovante de envio de cada missão.

**Proibido:** dados pessoais de colegas ou visitantes, chaves de API, evidência simulada.
